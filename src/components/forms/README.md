# components/forms

Form primitives and forms (Phase 4+): `Field`, `Input`, `Select`, `Textarea`, `Checkbox`,
`Chip`, `FileUpload`; `ContactForm`, `GatedDownloadForm` (ungated / form / success),
`SubscribeForm`. `SearchInput` is deferred (Knowledge / Resource search only).
Labels always above fields; errors are text plus a 4px orange bar; controls are at least 48px tall.
